# Wombat (formerly WAF++)

**Wombat** — previously **WAF++** (Well-Architected Framework++) — is a
community-driven, cloud-agnostic framework for assessing cloud and platform
architectures. It gives teams a vendor-neutral way to make architectural
decisions measurable, traceable, and audit-ready.

- 🌐 Website: https://www.wombat-gov.dev/
- 📖 Documentation: https://www.wombat-gov.dev/docs/wafpp/1.1.0-en/
- 🧭 Controls: https://www.wombat-gov.dev/controls/
- 🗳️ RFC tracker: https://www.wombat-gov.dev/rfc/

---

## 🌐 Overview

Wombat helps organisations design secure, scalable, and efficient
architectures without tying them to a single cloud provider. Its mission is to
provide best practices, governance models, and practical tooling so teams can
deliver high-quality solutions across different cloud environments.

The framework covers **8 pillars**, **100+ controls**, **50+ compliance
frameworks**, and **15+ countries and regions**. Every control can be assessed,
scored, and evidenced.

---

## 🚀 Key features

- **Cloud-agnostic by design** — works across AWS, Azure, GCP, and other
  providers without vendor lock-in.
- **Community-driven** — developed and maintained by contributors in public.
- **Well-architected principles** — aligned with industry standards for
  reliability, security, cost, and performance.
- **Extensible framework** — includes architecture guidance, governance, and
  best practices that teams can adopt incrementally.
- **Evidence, not screenshots** — controls map to assessment results that can be
  verified and shared.
